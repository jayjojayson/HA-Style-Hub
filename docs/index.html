HA Style Hub

Configure the Home Assistant sidebar from a graphical panel: order, names, icons, visibility, a multi column grid layout and the complete look — including Settings, Notifications and the user entry, which Home Assistant normally keeps pinned to the bottom.

Die Seitenleiste von Home Assistant über eine grafische Oberfläche einrichten: Reihenfolge, Namen, Icons, Sichtbarkeit, ein mehrspaltiges Grid-Layout und das komplette Aussehen — inklusive Einstellungen, Benachrichtigungen und Benutzereintrag, die Home Assistant sonst fest am unteren Rand verankert.

Installation

Installation

HACS

  1. HACS → ⋮ → Custom repositories
  2. HACS → ⋮ → Benutzerdefinierte Repositories
  3. Add https://github.com/jayjojayson/HA-Style-Hub, category Integration
  4. https://github.com/jayjojayson/HA-Style-Hub als Kategorie Integration hinzufügen
  5. Install HA Style Hub and restart Home Assistant
  6. HA Style Hub installieren und Home Assistant neu starten
  7. Settings → Devices & services → Add integration → HA Style Hub
  8. Einstellungen → Geräte & Dienste → Integration hinzufügen → HA Style Hub

Manual

Manuell

Copy the folder custom_components/ha_style_hub into your Home Assistant configuration:

Den Ordner custom_components/ha_style_hub in die Home-Assistant-Konfiguration kopieren: 

config/
└── custom_components/
    └── ha_style_hub/
        ├── __init__.py
        ├── card_yaml.py
        ├── config_flow.py
        ├── const.py
        ├── manifest.json
        ├── media.py
        ├── runtime.py
        ├── store.py
        ├── switch.py
        ├── theme.py
        ├── websocket_api.py
        ├── translations/
        └── www/
            ├── ha-style-hub.js
            └── ha-style-hub-panel.js

Restart Home Assistant, then add the integration.

Home Assistant neu starten, danach die Integration hinzufügen.

Requirements: Home Assistant 2025.3 or newer. The full tile look (icon above the label) needs 2026.5 or newer, because only that sidebar generation exposes the required CSS parts. Voraussetzungen: Home Assistant 2025.3 oder neuer. Die vollständige Kachelansicht (Icon über der Beschriftung) braucht 2026.5 oder neuer, weil erst diese Generation der Seitenleiste die nötigen CSS-Parts bereitstellt.

Usage

Bedienung

After the installation a HA Style Hub entry appears in the sidebar and opens the configuration panel. Since 1.4.0 every page is a stage: on the left a model of Home Assistant, on the right the fields. A click in the model on what you want to change — an entry of the sidebar, the header bar, a card, the menu entries of the Settings page — opens its fields; the chosen part is outlined and labelled. The bar at the top holds the four areas Sidebar, Theme, Header and HA-Settings, a search over all settings (Ctrl K), the counter of unsaved changes, Discard, Save and the history, plus icons for Export / Import and Info. A changed field shows a dot and its previous value; Before below the preview shows the saved state. On a phone the areas sit in a bar at the bottom.

Nach der Installation erscheint der Eintrag HA Style Hub in der Seitenleiste und öffnet das Konfigurationspanel. Seit 1.4.0 ist jede Seite eine Bühne: links ein nachgebautes Home Assistant, rechts die Felder. Ein Klick im Bild auf das, was du ändern willst — einen Eintrag der Seitenleiste, die Kopfzeile, eine Karte, die Menüpunkte der Einstellungsseite — öffnet seine Felder; das gewählte Element ist umrandet und beschriftet. Die Kopfleiste trägt die vier Bereiche Sidebar, Theme, Header und HA-Settings, eine Suche über alle Einstellungen (Strg K), den Zähler der ungespeicherten Änderungen, Verwerfen, Speichern und den Verlauf, dazu die Symbole für Export / Import und Info. Ein geändertes Feld zeigt einen Punkt und den Wert von vorher; Vorher unter dem Bild zeigt den gespeicherten Stand. Auf dem Handy stehen die Bereiche in einer Leiste unten.

LayoutColumns, gap, sidebar width, tile and row height, whether the fixed entries join the grid, the optional restart button and Hide the sidebar completely (kiosk mode) at the bottom of the column, shown right away in the model of the sidebar next to the fields.
LayoutSpalten, Abstand, Breite der Seitenleiste, Kachel- und Zeilenhöhe, die Übernahme der festen Einträge ins Raster, der optionale Neustart-Knopf und Sidebar ganz ausblenden (kiosk-mode) unten in der Spalte, sofort sichtbar im Modell der Seitenleiste neben den Feldern.
EntriesA click on an entry in the model of the sidebar selects it, dragging it there reorders it. In the list on the right (drag and drop, eye) the chosen entry folds open with its fields — name, icon, column span, the colors as tiles, hide, up / down, reset. Section headings are added with the + button. The plus adds a section heading, a link to a page of Home Assistant (automations, entities, tools, ... or an own path) as a normal sidebar entry, or a popup link: one entry that opens a window with several pages or with a card (YAML from the code editor of a dashboard card, at most 50 KB); width and height of the window can be set, 0 = automatic.
EinträgeEin Klick auf einen Eintrag im Bild der Seitenleiste wählt ihn aus, Ziehen dort sortiert um. In der Liste rechts (Drag and Drop, Auge) klappt der gewählte Eintrag mit seinen Feldern auf — Name, Icon, Spaltenbreite, die Farben als Kacheln, Ausblenden, nach oben / unten, Zurücksetzen. Zwischenüberschriften legt der +-Knopf an. Das Plus fügt eine Zwischenüberschrift, einen Link zu einer Seite von Home Assistant (Automatisierungen, Entitäten, Werkzeuge, … oder ein eigener Pfad) als normalen Eintrag der Seitenleiste oder einen PopUp-Link ein: ein Eintrag, der ein Fenster mit mehreren Seiten oder mit einer Karte öffnet (YAML aus dem Code-Editor einer Dashboard-Karte, höchstens 50 KB); Breite und Höhe des Fensters lassen sich einstellen, 0 = automatisch.
AppearanceBackground and gradients, text and icon colors, font size and weight, icon size, borders, radius, title and free CSS. A click on a part of the sidebar in the model opens its group.
AussehenHintergrund und Verläufe, Text- und Iconfarben, Schriftgröße und -stärke, Icongröße, Rahmen, Radius, Titel und eigenes CSS. Ein Klick auf einen Teil der Seitenleiste im Bild öffnet seine Gruppe.
HeaderThe bar at the top of a dashboard: colors and gradient, opacity and blur, height, border and corners, a border around each button and view tab, icon and title / tab size, the colors of the view tabs — or hidden completely. The four buttons Home Assistant puts at the right end — add, search, Assist and edit — can be switched off one by one. The header bar is selected in the model; a click on the view tabs or the buttons opens their group, Simple expands only that group and All fields all of them, three templates are a starting point. The bar can sit at the top or at the bottom of the dashboard. Hiding it is also available as a switch entity for a dashboard button. The card Buttons on the right side can also put the restart button and own links to pages of Home Assistant and sensors (the state of any entity, a click opens its more-info dialog) in front of Home Assistant's buttons, as well as CPU and memory and the free and used storage space as small values; the view tabs have a hover background, and the right side of the header (buttons, links, CPU/RAM) can get a colour of its own.
HeaderDie Kopfzeile eines Dashboards: Farben und Verlauf, Deckkraft und Weichzeichner, Höhe, Rahmen und Ecken, ein Rahmen um jeden Button und Reiter, Icon- und Titel-/Reitergröße, die Farben der Ansichts-Reiter — oder ganz ausgeblendet. Die vier Button, die Home Assistant rechts hineinsetzt — Hinzufügen, Suche, Assist und Bearbeiten —, lassen sich einzeln abschalten. Die Kopfzeile ist im Bild ausgewählt; ein Klick auf die Reiter oder die Buttons öffnet ihre Gruppe, Einfach klappt nur diese Gruppe auf und Alle Felder alle, drei Vorlagen sind ein Ausgangspunkt. Die Leiste steht wahlweise oben oder unten im Dashboard. Das Ausblenden gibt es zusätzlich als Schalter-Entität für einen Button auf dem Dashboard. Die Karte Buttons rechte Seite setzt außerdem den Neustart-Button und eigene Links zu Seiten von Home Assistant und Sensoren (der Zustand einer beliebigen Entität, ein Klick öffnet ihren Mehr-Info-Dialog) vor die Buttons von Home Assistant, dazu CPU und RAM sowie den freien und belegten Speicherplatz als kleine Werte; die Reiter der Ansichten haben einen Maus-Hover, und die rechte Seite der Kopfzeile (Buttons, Links, CPU/RAM) bekommt auf Wunsch eine eigene Farbe.
HA-SettingsSettings for Home Assistant itself: the model shows the Settings page, Devices & services or a table (picked at the top of the field column); a click on the menu entries, the favourites bar or the system monitor opens its fields (Before shows the saved state). Menu entries of the Settings page: Home Assistant draws a colored circle behind every icon. Switch on Menu entries as rounded boxes and it becomes a box with an adjustable corner radius (0 is sharp, large values give the circle back). On top of that you can set one box color for all entries (empty: every entry keeps its own), the icon color, the box size and the icon size in px; 0 means "as Home Assistant draws it". Devices & services as a list: the integrations are shown as slim rows instead of a grid of cards - name on the left, count and symbols on the right. Row height (56 px by default, at least 32), gap between rows and a maximum width of the list (0 is the full width) can be set, the list can run in two or three columns (fewer by itself on a narrow screen), as well as border width, corner radius (each side and corner separately if you like) and border color of the rows, a separate border color for integrations with a problem and a hover color with opacity. The menu entries get a border and corners of their own, too. Optionally the Apps page becomes a list as well, and the group headers of the tables (automations, entities, helpers, ...) get a background, text color, size and weight of their own; the rows of the tables can get a colour of their own and one for every second row, a hover colour with opacity and a font size (0 or 10 to 24 px). Settings page: order and favourites (columns and tiles are set in the card of the menu entries): the menu entries of Home Assistant's Settings page can be moved inside their block and hidden (a block in which everything is hidden disappears), shown in one, two or three columns (the page then gets 960 or 1040 px wide; Settings › System follows) and as tiles with the icon above the name; a favourites bar puts up to 12 own links as buttons, centred above the cards or in the header bar of the Settings page, each with its own look (colours, icon, height, border, corners, icon only). A system monitor shows processor, memory and storage on the Settings page, at the top or at the end, optionally with graphs of the last 5 minutes and a storage bar. A box of its own shows the last backup (when, size, name, location), a third one counters (devices, entities, integrations, apps, automations, scenes, scripts, custom cards, blueprints, users, tokens - you choose, most with a second line such as unreachable devices or the memory of the apps), and the menu entries get a mouse hover that also applies to the system monitor and the backup box; the tip line below the menu can be hidden. The list of entries shows what the Settings page had when it was last open in this browser. The whole page can be exported and imported as a JSON file (page Export / Import). These functions work on the structure of the pages as found in the Home Assistant source and only touch those elements on pages under /config; should a later version change it, the pages simply stay as Home Assistant draws them.
HA-SettingsEinstellungen für Home Assistant selbst: das Bild zeigt die Einstellungsseite, Geräte & Dienste oder eine Tabelle (gewählt oben in der Feldspalte); ein Klick auf die Menüpunkte, die Favoriten-Leiste oder den Systemmonitor öffnet ihre Felder (Vorher zeigt den gespeicherten Stand). Menüpunkte der Einstellungsseite: Home Assistant zeichnet hinter jedes Symbol einen farbigen Kreis. Mit Menüpunkte als abgerundete Boxen wird daraus eine Box mit einstellbarem Eckenradius (0 ist eckig, große Werte ergeben wieder den Kreis). Dazu lassen sich eine Farbe der Box für alle Menüpunkte (leer: jeder behält seine eigene), die Farbe des Symbols, die Größe der Box und die Größe des Symbols in px einstellen; 0 heißt „wie Home Assistant es zeichnet“. Geräte & Dienste als Liste: die Integrationen erscheinen als schmale Zeilen statt als Raster aus Karten — der Name links, Anzahl und Symbole rechts. Zeilenhöhe (Standard 56 px, mindestens 32), Abstand zwischen den Zeilen und eine maximale Breite der Liste (0 ist die volle Breite) sind einstellbar, die Liste kann zwei- oder dreispaltig laufen (auf schmalen Bildschirmen von selbst weniger Spalten), ebenso Rahmenstärke, Eckenradius (auf Wunsch je Seite und je Ecke einzeln) und Rahmenfarbe der Zeilen, eine eigene Rahmenfarbe für Integrationen mit Problem sowie eine Hover-Farbe mit Deckkraft. Auch die Menüpunkte bekommen einen eigenen Rahmen und eigene Ecken. Auf Wunsch wird auch die Apps-Seite zur Liste, und die Gruppenköpfe der Tabellen (Automatisierungen, Entitäten, Helfer, …) bekommen eigenen Hintergrund, eigene Textfarbe, Größe und Stärke; die Zeilen der Tabellen können eine eigene Farbe und eine Farbe für jede zweite Zeile, eine Hover-Farbe mit Deckkraft und eine Schriftgröße (0 oder 10 bis 24 px) bekommen. Einstellungsseite: Reihenfolge und Favoriten (Spalten und Kacheln stehen in der Karte der Menüpunkte): Die Menüpunkte der Einstellungsseite von Home Assistant lassen sich innerhalb ihres Blocks verschieben und ausblenden (ein Block, in dem alles ausgeblendet ist, verschwindet), in einer, zwei oder drei Spalten anzeigen (die Seite wird dann 960 bzw. 1040 px breit; Einstellungen › System zieht mit) und als Kacheln mit dem Symbol über dem Namen; eine Favoriten-Leiste setzt bis zu 12 eigene Links als Buttons mittig über die Karten oder in die Kopfleiste der Einstellungsseite, jeweils mit eigenem Aussehen (Farben, Icon, Höhe, Rahmen, Ecken, nur Icon). Ein Systemmonitor zeigt Prozessor, Arbeitsspeicher und Speicher auf der Einstellungsseite, oben oder am Ende, auf Wunsch mit Verläufen der letzten 5 Minuten und einem Speicherbalken. Eine eigene Box zeigt das letzte Backup (wann, Größe, Name, Speicherort), eine dritte Zähler (Geräte, Entitäten, Integrationen, Apps, Automationen, Szenen, Skripte, Custom Cards, Blueprints, Benutzer, Token – nach Wahl, die meisten mit einer zweiten Zeile wie nicht erreichbare Geräte oder dem Speicher der Apps), und die Menüpunkte bekommen einen Maus-Hover, der auch für Systemmonitor und Backup-Box gilt; die Tipp-Zeile unter dem Menü lässt sich ausblenden. Die Liste der Menüpunkte zeigt, was die Einstellungsseite hatte, als sie zuletzt in diesem Browser geöffnet war. Die ganze Seite lässt sich als JSON-Datei exportieren und importieren (Seite Export / Import). Diese Funktionen arbeiten mit dem Aufbau der Seiten, wie er im Quelltext von Home Assistant steht, und fassen nur diese Elemente auf Seiten unter /config an; ändert eine spätere Version ihn, bleiben die Seiten einfach so, wie Home Assistant sie zeichnet.
HistoryThe clock icon next to Save and Discard opens the last 10 saved states, newest first, each with the time, the person who saved it and what changed (counted by area, e.g. "Header: 3 values"). Restore loads a state into the page — it is only stored when you press Save, and Discard takes it back. Hiding the header and the sidebar are switches and stay as they are; a save that changes nothing is not recorded, a reset is. Administrators only; the history lives in .storage/ha_style_hub.history.
VerlaufDas Uhr-Symbol neben Speichern und Verwerfen öffnet die letzten 10 gespeicherten Stände, der neueste oben, jeweils mit Zeit, dem Speichernden und den Änderungen (nach Bereichen gezählt, z. B. „Header: 3 Werte“). Wiederherstellen lädt einen Stand in die Seite — gespeichert wird erst mit Speichern, Verwerfen nimmt ihn zurück. Das Ausblenden von Kopfzeile und Seitenleiste sind Schalter und bleiben, wie sie sind; ein Speichern ohne Änderung wird nicht festgehalten, ein Zurücksetzen schon. Nur für Administratoren; der Verlauf liegt in .storage/ha_style_hub.history.
ThemeThe colors of Home Assistant itself — dashboards, dialogs and the settings pages — as a real theme. The model shows every colourable element; a click opens its groups. Templates and a palette from one color give you a finished look to start from, themes can be exported and imported as YAML. The card shadow can be designed with templates and sliders instead of CSS. The scale of the primary color for newer controls (--ha-color-primary-05 … 95) is computed automatically, like Home Assistant does for its default theme.
Export / ImportOne page for everything: the complete configuration as .json, and sidebar (new in 1.4.0), theme (.yaml), header and HA-Settings on their own. An import is taken into the page at once and only stored with Save; until then Discard brings back the saved state.
InfoWelcome text, author and links, support, the master switch HA Style Hub active, debug output in the browser console and Reset everything.
ThemeDie Farben von Home Assistant selbst — Dashboards, Dialoge und Einstellungsseiten — als echtes Theme. Das Bild zeigt alle färbbaren Elemente; ein Klick öffnet ihre Gruppen. Vorlagen und eine Farbpalette aus einer Hauptfarbe liefern einen fertigen Ausgangspunkt, Themes lassen sich als YAML exportieren und importieren. Den Schatten der Karten gestaltest du mit Vorlagen und Reglern statt mit CSS. Die Abstufungen der Primärfarbe für neuere Bedienelemente (--ha-color-primary-05 … 95) berechnet die Integration automatisch, wie Home Assistant beim Standard-Theme.
Export / ImportEine Seite für alles: die komplette Konfiguration als .json sowie Sidebar (neu in 1.4.0), Theme (.yaml), Header und HA-Settings einzeln. Ein Import wird sofort in die Seite übernommen und erst mit Speichern abgelegt; bis dahin holt Verwerfen den gespeicherten Stand zurück.
InfoWillkommenstext, Autor und Links, Unterstützung, der Hauptschalter HA Style Hub aktiv, Debug-Ausgaben in der Browser-Konsole und Alles zurücksetzen.
Every change is applied to the sidebar immediately, but only written to .storage when you press Save. Discard returns to the stored state. Jede Änderung wirkt sich sofort auf die Seitenleiste aus, gespeichert wird sie in .storage aber erst mit Speichern. Verwerfen stellt den gespeicherten Stand wieder her.

Moving Settings, Notifications and the user entry

Einstellungen, Benachrichtigungen und Profil verschieben

Home Assistant renders those three in a separate block that is pinned to the bottom of the sidebar. Switch on "Move Settings, Notifications and the user entry into the grid" in the Layout tab — only then do they become part of the sortable grid.

Home Assistant rendert diese drei in einem eigenen Block, der unten in der Seitenleiste verankert ist. Im Reiter Layout die Option „Einstellungen, Benachrichtigungen und Profil ins Raster übernehmen“ aktivieren — erst dann werden sie Teil des sortierbaren Rasters.

Section headings divide the sidebar into blocks. The + in the Entries box adds one: it takes a name, an icon and its own colors, runs across the full width and has no target. While the sidebar is collapsed it is hidden — there is no room for text there, and an icon on its own would look like another entry. Drag it to the place it belongs, the bin icon removes it. Border and corner radius work like they do for entries: one value, or one per side and per corner.

Drag an entry a little to the right to file it under the heading above it; dragging it back to the left takes it out. With “Can be collapsed” switched on in the heading row, a click on the heading in the sidebar folds the whole group away. Which headings are folded is remembered per browser — it is a view, not a setting. Zwischenüberschriften unterteilen die Seitenleiste in Blöcke. Der +-Knopf in der Box Einträge legt eine an: sie bekommt Name, Icon und eigene Farben, läuft über die ganze Breite und hat kein Ziel. Im eingeklappten Zustand ist sie ausgeblendet — dort ist kein Platz für Text, und ein Icon allein sähe aus wie ein weiterer Eintrag. Zieh sie an die gewünschte Stelle, der Papierkorb entfernt sie wieder. Rahmen und Eckenradius lassen sich wie bei den Einträgen als Gesamtwert oder je Seite und je Ecke festlegen.

Zieh einen Eintrag etwas nach rechts, um ihn unter der Überschrift darüber einzusortieren; nach links löst die Zuordnung wieder. Ist in der Überschriftenzeile „Lässt sich zusammenklappen“ aktiv, klappt ein Klick auf die Überschrift in der Seitenleiste die ganze Gruppe weg. Welche Überschriften zugeklappt sind, merkt sich jeder Browser selbst — es ist eine Ansicht, keine Einstellung.

The theme

Das Theme

The Theme tab does not style the sidebar, it styles Home Assistant itself: dashboards, dialogs and the settings pages. What is entered there is registered as a real Home Assistant theme, exactly like a theme from configuration.yaml — it shows up in the theme picker of every user profile.

Der Reiter Theme gestaltet nicht die Seitenleiste, sondern Home Assistant selbst: Dashboards, Dialoge und die Einstellungsseiten. Was dort eingetragen wird, meldet die Integration als echtes Home-Assistant-Theme an — genau wie ein Theme aus der configuration.yaml. Es steht danach in der Theme-Auswahl jedes Benutzerprofils.

How it works

Funktionsweise

HA Style Hub has two halves:

HA Style Hub besteht aus zwei Hälften:

  • a Python backend that keeps the configuration in .storage, serves it over the websocket API (ha_style_hub/get, ha_style_hub/save, ha_style_hub/reset) and delivers the two JavaScript files
  • ein Python-Backend, das die Konfiguration in .storage hält, sie über die Websocket-API bereitstellt (ha_style_hub/get, ha_style_hub/save, ha_style_hub/reset) und die beiden JavaScript-Dateien ausliefert
  • a frontend module that is loaded on every page, walks the shadow DOM down to ha-sidebar and adopts generated stylesheets into the relevant shadow roots
  • ein Frontend-Modul, das auf jeder Seite geladen wird, sich durch den Shadow DOM bis zur ha-sidebar hangelt und generierte Stylesheets in die betroffenen Shadow Roots einhängt

The order is not produced by moving DOM nodes. The entries are laid out in a CSS grid and sorted with the order property, so Home Assistant's own rendering stays intact and survives every re-render without further work. The three fixed entries join the grid because the containers between them and the grid are set to display: contents.

Die Reihenfolge entsteht nicht durch Verschieben von DOM-Knoten. Die Einträge liegen in einem CSS-Grid und werden über die Eigenschaft order sortiert. So bleibt das Rendering von Home Assistant unangetastet und übersteht jedes Neuzeichnen von selbst. Die drei festen Einträge landen im Raster, weil die Container dazwischen auf display: contents gesetzt werden.

After saving, the backend fires the event ha_style_hub_updated, so every open browser picks up the new configuration without a reload.

Nach dem Speichern feuert das Backend das Ereignis ha_style_hub_updated, sodass jeder offene Browser die neue Konfiguration ohne Neuladen übernimmt.

FAQ

The sidebar does not change at all

Die Seitenleiste ändert sich überhaupt nicht

Reload the page with a hard refresh so the browser picks up the new module. Switch on the debug output under Sidebar › Layout › HA Style Hub Settings and look for [HA Style Hub] in the browser console - there is a line per area ([sidebar], [theme], [header], [settings]).

Die Seite mit einem harten Neuladen aktualisieren, damit der Browser das Modul neu holt. Unter Sidebar › Layout › HA Style Hub Settings die Debug-Ausgaben aktivieren und in der Browser-Konsole nach [HA Style Hub] schauen - je Bereich gibt es eine Zeile ([sidebar], [theme], [header], [settings]).

Settings and the user entry stay at the bottom

Einstellungen und Profil bleiben unten

Switch on "Move Settings, Notifications and the user entry into the grid" in the Layout tab.

Im Reiter Layout die Option „Einstellungen, Benachrichtigungen und Profil ins Raster übernehmen“ aktivieren.

Is it per user?

Gilt das pro Benutzer?

No. Version 1.1.1 stores one configuration for the whole installation. Hiding entries is a layout choice, not a permission — Home Assistant's own admin rules still apply.

Nein. Version 1.1.1 speichert eine Konfiguration für die gesamte Installation. Das Ausblenden von Einträgen ist eine Layout-Entscheidung und keine Berechtigung — die Admin-Regeln von Home Assistant gelten weiterhin.

Does it collide with custom-sidebar?

Kollidiert es mit custom-sidebar?

Both tools patch the same element. Use only one of them at a time.

Beide Werkzeuge greifen dasselbe Element an. Immer nur eines von beiden verwenden.

How do I get back to the stock sidebar?

Wie komme ich zur Originalseitenleiste zurück?

Switch off "HA Style Hub active" on the Info page (the i icon at the top right of the panel), or remove the integration entirely.

Auf der Seite Info (das i-Symbol oben rechts im Panel) die Option „HA Style Hub aktiv“ abschalten oder die Integration ganz entfernen.
