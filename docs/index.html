Installation

HACS

  1. HACS → ⋮ → Custom repositories
  2. HACS → ⋮ → Benutzerdefinierte Repositories
  3. Add https://github.com/jayjojayson/HA-Style-Hub, category Integration
  4. https://github.com/jayjojayson/HA-Style-Hub als Kategorie Integration hinzufügen
  5. Install HA Style Hub and restart Home Assistant
  6. HA Style Hub installieren und Home Assistant neu starten
  7. Settings → Devices & services → Add integration → HA Style Hub
  8. Einstellungen → Geräte & Dienste → Integration hinzufügen → HA Style Hub

Manual

Manuell

Copy the folder custom_components/ha_style_hub into your Home Assistant configuration:

Den Ordner custom_components/ha_style_hub in die Home-Assistant-Konfiguration kopieren:

config/
└── custom_components/
    └── ha_style_hub/
        ├── __init__.py
        ├── manifest.json
        ├── …
        ├── translations/
        └── www/
            ├── ha-style-hub.js
            └── ha-style-hub-panel.js

Restart Home Assistant, then add the integration.

Home Assistant neu starten, danach die Integration hinzufügen.

Requirements: Home Assistant 2025.3 or newer. The full tile look (icon above the label) needs 2026.5 or newer, because only that sidebar generation exposes the required CSS parts.

Voraussetzungen: Home Assistant 2025.3 oder neuer. Die vollständige Kachelansicht (Icon über der Beschriftung) braucht 2026.5 oder neuer, weil erst diese Generation der Seitenleiste die nötigen CSS-Parts bereitstellt.

Usage

Bedienung

After the installation a HA Style Hub entry appears in the sidebar and opens the configuration panel. Every page is a stage: on the left a model of Home Assistant, on the right the fields. Click in the model on what you want to change — the chosen part is outlined and labelled, and its fields open.

Nach der Installation erscheint der Eintrag HA Style Hub in der Seitenleiste und öffnet das Konfigurationspanel. Jede Seite ist eine Bühne: links ein nachgebautes Home Assistant, rechts die Felder. Klick im Bild auf das, was du ändern willst — das gewählte Element wird umrandet und beschriftet, seine Felder öffnen sich.

  • Export / Import: the complete configuration as .json, and sidebar, theme (.yaml), header and HA-Settings on their own. An import is taken into the page at once and only stored with Save; until then Discard brings back the saved state.

The theme

Das Theme

The Theme tab does not style the sidebar, it styles Home Assistant itself: dashboards, dialogs and the settings pages. What is entered there is registered as a real Home Assistant theme, exactly like a theme from configuration.yaml — it shows up in the theme picker of every user profile.

Der Reiter Theme gestaltet nicht die Seitenleiste, sondern Home Assistant selbst: Dashboards, Dialoge und die Einstellungsseiten. Was dort eingetragen wird, meldet die Integration als echtes Home-Assistant-Theme an — genau wie ein Theme aus der configuration.yaml. Es steht danach in der Theme-Auswahl jedes Benutzerprofils.

Good to know

Gut zu wissen

  • Dark and light are stored separately. A switch decides which one is edited; “Copy to light / dark” takes one over to the other, “Clear this mode” empties it.
  • Dunkel und Hell werden getrennt gespeichert. Ein Schalter bestimmt den bearbeiteten Modus; „Nach Hell/Dunkel kopieren“ überträgt den einen in den anderen, „Diesen Modus leeren“ löscht ihn.
  • Empty = untouched. Only filled fields end up in the theme; everything else keeps the value Home Assistant brings along.
  • Leer = unverändert. Nur ausgefüllte Felder landen im Theme; alles andere behält den Wert von Home Assistant.
  • Preview: three mock cards — a dashboard, a settings page and a dialog with a code editor — show the mode being edited, font, scale and weight included. On a wide screen it stays anchored while the fields scroll.
  • Vorschau: drei nachgebaute Karten — Dashboard, Einstellungsseite und Dialog mit Code-Editor — zeigen den bearbeiteten Modus, Schriftart, Skalierung und Stärke eingeschlossen. Auf breiten Bildschirmen bleibt sie stehen, während die Felder scrollen.
  • Border and radius of the cards can be set per side and per corner, like the sidebar entries.
  • Rahmen und Eckenradius der Karten lassen sich je Seite und je Ecke festlegen, wie bei den Einträgen der Seitenleiste.
  • Card shadow: designed with templates and sliders instead of CSS.
  • Kartenschatten: mit Vorlagen und Reglern statt mit CSS gestaltet.
  • Primary scale (--ha-color-primary-05 … 95) is computed automatically, like Home Assistant does for its default theme.
  • Primärfarben-Abstufung (--ha-color-primary-05 … 95) berechnet die Integration automatisch, wie Home Assistant beim Standard-Theme.

How it works

Funktionsweise

HA Style Hub has two halves:

HA Style Hub besteht aus zwei Hälften:

🐍 Python backendPython-Backend

  • keeps the configuration in .storage
  • hält die Konfiguration in .storage
  • serves it over the websocket API (ha_style_hub/get, save, reset)
  • stellt sie über die Websocket-API bereit (ha_style_hub/get, save, reset)
  • delivers the two JavaScript files
  • liefert die beiden JavaScript-Dateien aus
⇄

🧩 Frontend moduleFrontend-Modul

  • is loaded on every page
  • wird auf jeder Seite geladen
  • walks the shadow DOM down to ha-sidebar
  • hangelt sich durch den Shadow DOM bis zur ha-sidebar
  • adopts generated stylesheets into the relevant shadow roots
  • hängt generierte Stylesheets in die betroffenen Shadow Roots ein

The order is not produced by moving DOM nodes. The entries are laid out in a CSS grid and sorted with the order property, so Home Assistant's own rendering stays intact and survives every re-render without further work. The three fixed entries join the grid because the containers between them and the grid are set to display: contents.

Die Reihenfolge entsteht nicht durch Verschieben von DOM-Knoten. Die Einträge liegen in einem CSS-Grid und werden über die Eigenschaft order sortiert. So bleibt das Rendering von Home Assistant unangetastet und übersteht jedes Neuzeichnen von selbst. Die drei festen Einträge landen im Raster, weil die Container dazwischen auf display: contents gesetzt werden.

After saving, the backend fires the event ha_style_hub_updated, so every open browser picks up the new configuration without a reload.

Nach dem Speichern feuert das Backend das Ereignis ha_style_hub_updated, sodass jeder offene Browser die neue Konfiguration ohne Neuladen übernimmt.

Thanks to UIX: the way the stylesheets get into the shadow roots at the right moment — wait for customElements.whenDefined, then hook the element's updated method — follows the approach of UIX, the successor of card-mod. Many thanks to its author for the groundwork. UIX does not have to be installed.

Danke an UIX: der Weg, wie die Stylesheets zum richtigen Zeitpunkt in die Shadow Roots gelangen — warten auf customElements.whenDefined, dann die Methode updated des Elements einklinken — folgt dem Ansatz von UIX, dem Nachfolger von card-mod. Vielen Dank an den Autor für die Vorarbeit. UIX muss dafür nicht installiert sein.

FAQ

The sidebar does not change at allDie Seitenleiste ändert sich überhaupt nicht

Reload the page with a hard refresh so the browser picks up the new module. Switch on the debug output under Sidebar › Layout › HA Style Hub Settings and look for [HA Style Hub] in the browser console — there is a line per area ([sidebar], [theme], [header], [settings]).

Die Seite mit einem harten Neuladen aktualisieren, damit der Browser das Modul neu holt. Unter Sidebar › Layout › HA Style Hub Settings die Debug-Ausgaben aktivieren und in der Browser-Konsole nach [HA Style Hub] schauen — je Bereich gibt es eine Zeile ([sidebar], [theme], [header], [settings]).

Settings and the user entry stay at the bottomEinstellungen und Profil bleiben unten

Switch on “Move Settings, Notifications and the user entry into the grid” in the Layout tab.

Im Reiter Layout die Option „Einstellungen, Benachrichtigungen und Profil ins Raster übernehmen“ aktivieren.

Is it per user?Gilt das pro Benutzer?

No. HA Style Hub stores one configuration for the whole installation. Hiding entries is a layout choice, not a permission — Home Assistant's own admin rules still apply.

Nein. HA Style Hub speichert eine Konfiguration für die gesamte Installation. Das Ausblenden von Einträgen ist eine Layout-Entscheidung und keine Berechtigung — die Admin-Regeln von Home Assistant gelten weiterhin.

Does it collide with custom-sidebar?Kollidiert es mit custom-sidebar?

Both tools patch the same element. Use only one of them at a time.

Beide Werkzeuge greifen dasselbe Element an. Immer nur eines von beiden verwenden.

How do I get back to the stock sidebar?Wie komme ich zur Originalseitenleiste zurück?

Switch off “HA Style Hub active” on the Info page (the i icon at the top right of the panel), or remove the integration entirely.

Auf der Seite Info (das i-Symbol oben rechts im Panel) die Option „HA Style Hub aktiv“ abschalten oder die Integration ganz entfernen.
