Alles auf einmal oder jede Rubrik für sich.

Komplette Konfiguration

.json

Exportieren speichert die komplette Konfiguration - Seitenleiste, Theme, Header und HA-Settings - als .json-Datei. Importieren liest so eine Datei wieder ein.

Sidebar

.json

Exportieren speichert Layout, Einträge und Aussehen der Seitenleiste als .json-Datei. Importieren liest so eine Datei wieder ein. Betroffen ist nur die Seitenleiste, Theme, Header und HA-Settings bleiben unberührt.

Theme

.yaml

Exportieren speichert das Theme als .yaml-Datei - praktisch als Sicherung oder um es von Hand in die configuration.yaml zu übernehmen. Importieren liest so eine Datei wieder ein und füllt damit die Felder dieser Seite; Variablen, die diese Seite nicht kennt, bleiben liegen.

Importieren

Header

.json

Exportieren speichert diese Einstellungen als .json-Datei - praktisch als Sicherung oder um ein Aussehen weiterzugeben. Importieren liest so eine Datei wieder ein. Betroffen ist nur die Kopfzeile, Seitenleiste und Theme bleiben unberührt.

HA-Settings

.json

Der Export speichert die HA-Settings als .json-Datei – praktisch als Sicherung oder zum Weitergeben. Der Import liest eine solche Datei wieder ein. Angefasst werden nur diese Einstellungen; Seitenleiste, Theme und Header bleiben, wie sie sind.

Ein Import wird sofort in die Seite übernommen und erst mit „Speichern“ abgelegt. Der Stand davor bleibt im Verlauf.
